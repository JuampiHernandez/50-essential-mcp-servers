# blockchain & web3

heads up for this whole section: these touch real assets on chains where transactions are irreversible. the well-built ones never hold your private keys and always make you confirm in a separate wallet UI. that design is the whole point — respect it.

## 30. base mcp

coinbase's official onchain gateway, launched may 26, 2026. swap tokens, send funds, track a portfolio, hit defi protocols (uniswap, morpho, moonwell, aerodrome, avantis, bankr, virtuals) — all by chatting. oauth 2.1, fully non-custodial: the server never holds your private keys. when the agent requests a transaction it builds the call locally and stores it as a pending request that your base account retrieves for you to review and sign. nothing executes onchain without your approval in the base app.

- **install:** install base mcp inside a supported client (claude, chatgpt, cursor) and authenticate with your base account — base's official docs/blog have the current setup; no exact endpoint string is quoted here because it couldn't be verified to the character, and a wrong url on a money-moving server isn't worth the risk.
- **link:** https://github.com/base/base-mcp
- **gotcha:** the old `base-mcp` npm package is deprecated — do not `npx base-mcp`. and understand what you're authorizing: this can move real funds on an irreversible chain. the review-and-sign step in the base app is your safety net. never bypass it.

## 31. solana agent kit

onchain actions on solana — transfers, swaps, token ops.

- **install:** community server via npx, wallet key in env
- **link:** https://github.com/sendaifun/solana-agent-kit
- **gotcha:** many community solana servers want a hot private key in env. that's a real risk. prefer setups that sign in a separate wallet, and never put a key holding real funds in a config file.

## 32. thirdweb

deploy and interact with smart contracts across evm chains.

- **install:** thirdweb ships an mcp server; check thirdweb's docs for the current package/command and where to put your secret key
- **link:** https://portal.thirdweb.com
- **gotcha:** contract deploys are irreversible and cost gas. test on a testnet chain id first.

## 33. the graph

query onchain data via subgraphs without running an indexer.

- **install:** community server via npx
- **link:** https://thegraph.com/docs/
- **gotcha:** read-only by nature, low risk. mostly a data tool.

## 34. dune

onchain analytics — run and read dune queries from the agent.

- **install:** community server, dune api key in env
- **link:** https://dune.com/docs/api/
- **gotcha:** api credits are metered. a chatty agent can burn through a free tier fast.

## 35. etherscan

block explorer access — contract verification, tx lookups, abi fetch.

- **install:** community server via npx, etherscan api key in env
- **link:** https://docs.etherscan.io
- **gotcha:** read-only. fine to leave on.
